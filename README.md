# Knowledge base and Taskroom

Project knowledge is indexed in [knowledge-base/index.md](knowledge-base/index.md).

Open the local task board by double-clicking `app/start.cmd`, or run `python app/server.py --open` from this folder. The app uses http://127.0.0.1:8765 while the process is running.

See [app documentation](app/README.md) for board/calendar usage, synchronization, commands and recovery. Tasks are stored in `knowledge-base/tasks.json`; task Markdown is generated. Use the UI or helper for changes.
